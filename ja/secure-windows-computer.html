Windows パソコンを安全にする手順

Windows 11 向け · 2026年11月19日更新

「パソコンを守るには何をすればいいの？」とよく聞かれます。うれしいことに、必要なものはほとんど Windows に最初から入っています。いくつかの設定を一度確認するだけで大丈夫です。お客さまと一緒に行っている手順を、わかりやすくまとめました。

あわてずに進めてください。今日は一部だけ、残りは別の日でもかまいません。ここに書いてあることでパソコンが壊れることはありません。

どこから始める？ いちばん大切なのは手順 1〜3（全部で30分ほど）と、まだバックアップがない場合は手順 8 です。ほかは後回しでかまいません。難しそうな手順は飛ばして次へ進んでください。あとで戻ってきても、一緒にやってもかまいません。

このガイドのメニュー名は日本語版 Windows のものです。Windows がフランス語の場合はフランス語版のガイドを、英語の場合は英語版をご覧ください。

これからやること
  1. 「Windows セキュリティ」を確認する
  2. ウイルス対策ソフトは1つだけに
  3. Microsoft Defender が動いているか確認する
  4. 心配なときは「オフライン スキャン」
  5. 起動時に PIN を設定する
  6. Wi-Fi とルーターをしっかり守る
  7. スマートフォンと WhatsApp
  8. ファイルを自動でバックアップする
  9. メールとパスワードを守る
  10. 覚えておきたい習慣

用意しておくもの

  • パソコンのパスワード（設定している場合）。
  • インターネットのルーターの裏に貼ってあるラベル（Wi-Fi のキーが書いてあります）。
  • 新しいコードを書きとめる紙とペン。

覚えておくと便利な2つ：検索バーは、画面の下、Windows のマークの横にある「検索」の欄です（見当たらない場合は Windows のマークをクリックして、そのまま文字を入力します）。Windows キーは、キーボードの左下、Ctrl と Alt の間にある同じマークのキーです。

1.「Windows セキュリティ」を確認する

画面下の検索バーに「Windows セキュリティ」と入力して開きます。パソコンの守りを一覧できる画面です。

灰色でクリックできない設定がある場合は、別のウイルス対策ソフトが入っていることが多いです。先に手順 2 を行ってから戻ってきてください。

  1. 危険なサイトやプログラム。アプリとブラウザー コントロールをクリックし、青いリンク評価ベースの保護の設定を開きます。スイッチをすべてオンにします（ページのいちばん下までスクロールしてください）。危険とわかっているサイトやプログラムを開く前に、Windows が知らせてくれます。
  2. ファイアウォール。左上の ← で最初の画面に戻り、ファイアウォールとネットワーク保護をクリックします。3つのネットワークすべてに緑のチェックがついていれば大丈夫で、変えるところはありません。ファイアウォールはマンションの管理人のようなものです。住人は自由に出入りできますが、招かれていない人は入れません。
  3. もう一段の守り（任意、飛ばしてもかまいません）。最初の画面に戻り、デバイス セキュリティ › コア分離の詳細でメモリ整合性をオンにし、求められたら再起動します。Windows がオンにできない場合は、古い機器（プリンターなど）が原因のことが多いです。心配はいりません。ほかの守りで十分です。
  4. 更新。Windows セキュリティを閉じて設定を開きます（Windows キー + I）。Windows Update › 詳細オプションで「その他の Microsoft 製品の更新プログラムを受け取る」をオンにします。更新は、見つかったセキュリティの穴をすぐにふさいでくれます。
まだ Windows 10 ですか？ 2025年10月から、Windows 10 の無料のセキュリティ更新は終了しています。パソコンの古さによっては Windows 11 に移れる場合があります。いちばん簡単な方法を一緒に考えましょう。

2. ウイルス対策ソフトは1つだけに

なぜ？ Windows には無料でしっかりしたウイルス対策ソフトMicrosoft Defenderが最初から入っています。ところが多くのパソコンには、購入時やほかのソフトのダウンロードと一緒に入った「無料」のウイルス対策ソフトもあります。2つ同時に動くとパソコンが遅くなり、有料版を売るための通知がたくさん出ます。1つで十分です。
  1. 設定を開き、アプリ › インストールされているアプリを開きます。
  2. 検索欄に、もう1つのウイルス対策ソフトの名前を入力します。名前がわからない場合は、Windows セキュリティ › ウイルスと脅威の防止に、動いているソフトの名前が表示されます。「antivirus」や「セキュリティ」と入力してみるのも手です。
  3. その名前の行ごとに、右の… › アンインストールをクリックします。アンインストールの画面は最後まで進めてください。引き止めようとする画面が出ることが多いので、アンインストールすることをはっきり選びます。同じブランド名で複数の部品が入っている場合は、すべて削除します。
  4. ブラウザー（Edge または Chrome）で、右上の点が3つのメニュー › 拡張機能を開きます。拡張機能はブラウザーに追加される小さな部品です。そのウイルス対策ソフトの名前のものがあれば削除します。
  5. パソコンを再起動します。Microsoft Defender が自動で引き継ぎます。

お金を払ったウイルス対策ソフトで、更新も続いているなら、そのまま使ってかまいません。大切なのは2つ入れないことです。

3. Microsoft Defender が動いているか確認する

  1. もう一度Windows セキュリティ › ウイルスと脅威の防止を開きます。「Microsoft Defender ウイルス対策」と表示されていれば大丈夫です。
  2. 設定の管理をクリックし、次の4つのスイッチがオンになっているか確認します。
    • リアルタイム保護：開いたりダウンロードしたりするものを Defender が常に見張ります。
    • クラウド提供の保護：最新の脅威の一覧をインターネットで確認します。一覧は常に更新されています。
    • サンプルの自動送信：あやしいファイルを Microsoft に送って調べてもらいます。個人的な内容かもしれないファイルを送る前には、必ず確認があります。
    • 改ざん防止：悪いプログラムがこっそり Defender を止めるのを防ぎます。
  3. クイック スキャンを実行します（数分で終わります）。

「ランサムウェア防止」（ファイルを人質にとるプログラムへの対策）について、OneDrive の設定をすすめる黄色い表示が出ることがあります。今は無視をクリックしてかまいません。ファイルのバックアップの話で、手順 8 で落ち着いて説明します。

4. 心配なときは「オフライン スキャン」

なぜ？ あやしいプログラム（「無料の PDF 変換ソフト」や偽のお掃除ソフトなど）を入れてしまったときや、パソコンの様子がおかしいときに使います。このスキャンはパソコンを再起動し、Windows が起動する前に調べます。そのため、悪いプログラムが隠れることができません。
  1. 作業を保存し、開いている書類を閉じます。パソコンが再起動します。
  2. Windows セキュリティ › ウイルスと脅威の防止 › スキャンのオプションを開きます。
  3. Microsoft Defender オフライン スキャンを選び、今すぐスキャンをクリックします。
  4. 15分ほどでスキャンが終わり、Windows がふつうに起動します。

Defender が何か見つけた場合は、隔離してくれます。そのあと（確認するプログラム、変えるパスワード、メールなど）は、ガイド「ウイルスのあとに確認すること」を見てください。

5. 起動時に PIN を設定する

なぜ？ 何も聞かれずにすぐ開くパソコンがたくさんあります。そうすると、電源を入れた人（盗んだ人も）があなたのメールや書類、ブラウザーに保存したパスワードを見られてしまいます。起動時のコードで、その扉を閉めましょう。

いちばん簡単なのは4〜6桁のPINです。パスワードより早く入力でき、このパソコンでしか使えません。

  1. 設定 › アカウント › サインイン オプションを開きます。
  2. PIN (Windows Hello)をクリックし、セットアップをクリックします。
  3. 最初に今のパスワードを聞かれます。聞かれない場合は、パスワードが設定されていません。先にパスワード › 追加を行ってから戻ってきてください。
  4. コードを決めます。1234、0000、家族の誕生日は避けましょう。
  5. 紙に書いて家に保管します。ただし、パソコンに貼らないでください。

同じサインイン オプションの「しばらく操作しなかった場合に、もう一度サインインを求めるタイミング」は、PC のスリープを解除する時間を選びます。

試してみましょう：Windows キー + L を押すと画面がロックされ、コードで開きます。パソコンから離れるときのよい習慣にもなります。

6. Wi-Fi とルーターをしっかり守る

このガイドでいちばん技術的な手順です。自信がなければ、訪問のときまでとっておいてください。それまでも Wi-Fi はふつうに使えます。

なぜ？ Wi-Fi は電波で空中を飛んでいます。ルーターはそれを「暗号化」、つまり自分の機器だけが読めるように混ぜています。ところが、古い混ぜ方（TKIP と呼ばれます）をまだ受け付けるルーターがあり、悪意のある人はそれを破る方法を知っています。iPhone で Wi-Fi の名前の下に「セキュリティ保護が弱い」と出る場合、たいていこれが原因です。直すのはスマートフォンではなく、ルーターの設定です。
  1. Wi-Fi につながっているパソコンでブラウザーを開き、ウィンドウのいちばん上のアドレス欄（Google の検索欄ではなく、サイトのアドレスが表示される場所）にルーターのアドレスを入力して Enter を押します。アドレスはプロバイダーの説明書に書いてあります。フランスの Orange の Livebox なら 192.168.1.1 です。
  2. ログインします。パスワードは説明書かルーターのラベルにあります（Livebox ではふつう、セキュリティキーの最初の8文字です）。
  3. Wi-Fi のページ（「Wi-Fi 詳細設定」などの場合もあります）を開き、セキュリティ モードまたは暗号化の設定を探します。
  4. WPA2 と AES を選びます（ルーターに WPA3 があり、機器がすべて新しければ WPA3 でもかまいません）。「TKIP」「mixed（混在）」「WEP」「なし」と書いてあるものは避けます。
  5. Wi-Fi の名前とキーは変えないでください。機器は自動でつながり直します。
  6. 保存します。Wi-Fi が1分ほど切れてから戻ります。これはふつうのことです。
注意：ルーターのページでは「パスワードを忘れた」を絶対にクリックしないでください。ルーターが工場出荷時の状態に戻そうとし、すべてをつなぎ直すことになります。パスワードが通らなければ、そこでやめてください。Wi-Fi はこれまでどおり使えます。

とても古い機器がつながらなくなった場合は、その機器の解決策が見つかるまで、元の設定に戻すこともできます。

ルーターのページを開いたついでに

  • 家で誰がつながっている？ 接続中の機器の一覧のページ（「マイネットワーク」「デバイス」などが多いです）を探します。パソコン、スマートフォン、テレビ、プリンター…すべて見覚えがあるはずです。知らない機器があれば、いちばん簡単なのは Wi-Fi のキーを変えることです。キーを知っている人だけがつなぎ直せます（自分の機器すべてでキーを入れ直す必要があります）。
  • ゲスト用 Wi-Fi。多くのルーターに「ゲスト」用の Wi-Fi があります。来客用にオンにしておくと、インターネットは使えますが、あなたの機器には入れません。メインのキーを教える必要もありません。
  • WPS ボタン。キーを入力せずに機器をつなげるボタンです。使っていなければ、Wi-Fi の設定でオフにできます。入口が1つ減ります。
  • ルーターの更新はふつう、夜のうちにプロバイダーが自動で行います。ルーターの電源を入れたままにしておけば大丈夫です。
  • 最後に、ルーターのページの上にあるログアウトをクリックします。

7. スマートフォンと WhatsApp

スマートフォンにも、パソコンと同じくらい大切なものが入っています。メッセージ、写真、メール、そして銀行の確認コードを受け取るのもたいていスマートフォンです。いくつかの設定で十分です。

iPhone の場合（「設定」アプリ）

  • アップデート：一般 › ソフトウェアアップデート › 自動アップデート：すべてオンにします。
  • パスコード：Face IDとパスコード（または Touch IDとパスコード）。6桁で、123456 や誕生日は避けます。
  • 自動ロック：画面表示と明るさ › 自動ロック：1分または2分。
  • 盗難デバイスの保護：Face IDとパスコード › 盗難デバイスの保護。泥棒がコードを知っていても、自宅以外の場所ではパスワードを変えられません。「探す」がオンになっている必要があります。これは誰かに居場所を知らせるものではなく、スマートフォンを探したり消去したりするためのものです。決めるのはあなたです。
  • 誰が何を見られるか：プライバシーとセキュリティ › 安全チェック。位置情報や写真を見られる人が表示され、まとめて止めることができます。
  • 詐欺サイト：アプリ › Safari › 詐欺Webサイトの警告：オン。

Android のスマートフォンにも同じ設定があります。名前はメーカーによって少し違います。

WhatsApp の場合（右下の「あなた」または「設定」）

  • 2段階認証：アカウント › 2段階認証 › 有効にする。6桁の PIN（スマートフォンのコードとは別のもの）を決めて、書きとめておきます。この PIN がなければ、あなたの番号を知っていても、誰もほかのスマートフォンにあなたの WhatsApp を入れられません。
  • リンク済みデバイス：自分のパソコンやタブレットだけが表示されているか確認します。知らないものがあれば、タップしてログアウトします。
  • グループ：プライバシー › グループ › 連絡先。知らない人にグループに追加されるのを防ぎます。そうしたグループは詐欺であることが多いです。
  • 知らない人からの電話：プライバシー › 通話 › 不明な発信者を消音。
いちばん大切な決まり：SMS で届いたコードは、誰にも教えないでください。WhatsApp で「間違えて送ってしまった」と言ってくる「友だち」でも同じです。アカウントを乗っ取るいちばん多い手口です。迷ったら、その人に電話して確かめましょう。

8. ファイルを自動でバックアップする

なぜ？ パソコンは故障したり、盗まれたり、ウイルスでロックされたりすることがあります。写真や書類は取り戻せません。自動バックアップなら、考えなくても定期的にコピーをとってくれます。

Windows に入っている方法：ファイル履歴

Windows は、フォルダー（ドキュメント、ピクチャ、デスクトップ、ミュージック、ビデオ）を外付けディスクやバックアップ用の機器に1時間ごとに自動でコピーし、ファイルの古い版も残してくれます。

  1. 外付けディスクをつなぐか、バックアップ用の機器の電源が入っているか確認します。
  2. 検索バーに「ファイル履歴」と入力して開きます（コントロール パネルで開きます）。
  3. ディスクが表示されたらオンにするをクリックします。表示されない場合は、左のドライブの選択で選びます。パソコンではなくルーターにつながっている機器の場合は、ネットワークの場所の追加をクリックします。
  4. 詳細設定では「1時間ごと」「無期限」（または「領域が足りなくなるまで」）のままでかまいません。
  5. 最初のバックアップが終わるまで待ちます。時間がかかることがありますが、2回目からは早く終わります。

ちゃんと動くか確かめるために、一度試してみましょう。同じ画面で個人用ファイルの復元をクリックし、写真を1枚探します。試したことのないバックアップは、本当に使えるかわかりません。

「RAID」の機器をお持ちですか？

RAID の機器には、同じ内容を保つディスクが2台入っています。1台が壊れても、もう1台が引き継ぐので、ディスクの故障には強いです。ただ、完全なバックアップではありません。間違って消したファイルやウイルスで壊れたファイルは、2台から同時に消えてしまいます。また、盗難や火事のときはパソコンと機器が一緒になくなります。そこで、次の2つのコツです。

大きな違いを生む2つの備え

  • 古い版を残す。ファイル履歴はこれを自動で行います。ルーターにつながった機器の場合は、その設定で「スナップショット」や「バージョン履歴」を探してオンにします。ウイルスでファイルが壊れても、昨日の版に戻せます。
  • 家以外の場所にもコピーを。いちばん大切なファイル（家族の写真、大事な書類）は、家の外にもう1つコピーを置きましょう。インターネット上（OneDrive や Google Drive、下を参照）か、月に一度更新する小さなディスクを家族の家に預けるなどの方法があります。

ケーブルでパソコンにつなぐバックアップ用ディスクは、つなぎっぱなしにしないでください。週に一度、バックアップが終わるまでつなぎます。外してあるディスクはウイルスに狙われません。

インターネットにバックアップ：OneDrive または Google Drive

家の外にコピーを置くいちばん簡単な方法です。パソコンがインターネットにつながっているあいだ、フォルダーが自動でコピーされます。どちらか一方を選び、同じフォルダーに両方は使わないでください。

OneDrive の場合（Windows 11 に最初から入っています。Microsoft アカウントが必要です）：

  1. 画面の右下、時計の近くにある小さな雲をクリックします（見当たらなければ、先に小さな矢印 ^ をクリック）。求められたら Microsoft アカウントでサインインします。
  2. 右上の歯車をクリックし、設定を開きます。
  3. 同期とバックアップのバックアップを管理をクリックします。
  4. 守りたいフォルダー（デスクトップ、ドキュメント、ピクチャ）を選び、バックアップを開始をクリックします。

ファイルはパソコンの同じ場所に残ったまま、OneDrive にも入ります。ファイルの横の緑のチェックや雲のマークは、コピーが済んだしるしです。

Google Drive の場合（Google アカウントが必要です。たとえば Gmail のアドレス）：

  1. 「パソコン版 Google ドライブ」を検索し、Google の公式ページからダウンロードしてインストールします。
  2. Google アカウントでログインします。
  3. 時計の近くにある Google ドライブのアイコンをクリックし、歯車 › 設定を開きます。
  4. マイパソコンでフォルダを追加をクリックし、たとえばドキュメントを選んで、Google ドライブと同期、完了をクリックします。ほかの大切なフォルダーも同じようにします。

どちらにも共通して知っておきたいこと：

  • 無料の容量には限りがあります：Microsoft は 5 GB、Google は 15 GB（メールと共有）です。書類には十分ですが、何年分もの写真には足りないことが多いです。それ以上は有料のプランが必要です。比べてから選び、まずはいちばん大切なファイルから始めましょう。
  • パソコンで消したものはインターネット上でも消えます。ただし、OneDrive や Google Drive のサイトのごみ箱から30日ほどは取り戻せます。
  • このコピーの安全はアカウントしだいです。よいパスワードと2段階認証で守りましょう（手順 9 を参照）。

9. メールとパスワードを守る

なぜ？ メールは、ほかのすべてのアカウントの鍵です。「パスワードを忘れた」のリンクが届くのはメールだからです。メールに入られると、ほとんどどこにでも入られてしまいます。だから、まず守るのはメールです。
  1. メールの2段階認証をオンにする。パスワードに加えて、スマートフォンに届くコードが必要になります。ただし、新しい機器からログインするときだけです。アカウントの設定の「セキュリティ」で探します（Gmail、Outlook、Orange、Yahoo など、どこにもあります）。インターネットにバックアップしている場合は、Microsoft や Google のアカウントでも同じようにします。
  2. 再設定用の情報を確認する：同じ場所で、電話番号と予備のメールアドレスが自分のもので、最新になっているか確認します。
  3. 大切なサイトごとに別のパスワードを（メール、銀行、ネットショッピング）。1つのサイトでパスワードが盗まれても、ほかは守られます。
  4. 全部を覚えなくてすむように、ブラウザー（Edge または Chrome）に強いパスワードを考えてもらい、保存してもらいましょう。自動で入力してくれます。起動時の PIN（手順 5）でパソコンを守っていれば安全です。メールのパスワードだけは紙に書いて家に保管します。

10. 覚えておきたい習慣

  • 画面右下の小さな盾のマーク：緑なら大丈夫。黄色や赤なら、クリックすると Windows がやることを教えてくれます。
  • パソコンを「掃除する」「ロックを解除する」ためにお金を払うよう求める表示は詐欺です。閉じて、表示された番号には電話しないでください。
  • パスワードを聞いてきたり、クリックを急がせたりするメールや SMS：クリックせず、身近な人に聞きましょう。
  • パソコンから離れるときは Windows キー + L。
  • 大切なサイトごとに別のパスワード、そしてメールには2段階認証。
  • 自動バックアップ、古い版、そして大切なファイルは家の外にもコピーを。
