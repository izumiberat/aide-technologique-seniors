ウイルスのあとに確認すること

Windows 11 向け · 2026年11月21日更新

Microsoft Defender が「脅威」を見つけたと知らせてきましたか？ それとも、インターネットで見つけた「無料の PDF 変換ソフト」や「お掃除ソフト」「高速化ソフト」などを入れてしまい、心配になっていますか？ あわてなくて大丈夫です。よくあることで、ちゃんと直せます。こういうときにお客さまと一緒に行う確認を、順番にまとめました。

このガイドは、基本の設定を説明した「Windows パソコンを安全にする手順」の続きです。まだ見ていない方は、このあとにそちらも行ってください。同じことが起きるのを防げます。

このガイドのメニュー名は日本語版 Windows のものです。Windows がフランス語の場合はフランス語版のガイドを、英語の場合は英語版をご覧ください。

これからやること
  1. フル スキャンをする
  2. インストールされているプログラムを確認する
  3. ブラウザーを確認する
  4. 大切なパスワードを変える
  5. メールを確認する
  6. 銀行の情報を入力してしまった場合
  7. もう起きないように
知っておくと安心：Defender が何かを見つけると、「隔離」します。つまり、閉じこめて何もできないようにします。危険はもう取り除かれています。このあとの確認は、何も残っていないことを確かめ、念のためアカウントを守るためのものです。

1. フル スキャンをする

まず Microsoft Defender のオフライン スキャンを行います。Windows が起動する前にパソコンを調べるので、悪いプログラムが隠れられません。手順は最初のガイド（手順 4）にあります。15分ほどかかります。

次に、Windows セキュリティ › ウイルスと脅威の防止 › 保護の履歴を開きます。Defender が何を見つけ、どう処理したかがわかります。「検疫済み」または「削除済み」なら、もう大丈夫です。

2. インストールされているプログラムを確認する

大切：この手順では、見て紙に書きとめるだけにして、知らないものは削除しないでください。見慣れない名前の多くはふつうのもので、Windows やパソコン、プリンターのメーカーが入れたものです。迷ったら、削除する前に信頼できる人に聞いてください。
  1. インストールされているプログラム。設定（Windows キー + I） › アプリ › インストールされているアプリを開きます。上でインストール日の順に並べ替えると、新しいものが先に表示されます。あやしいプログラムはもうないはずです。まだあれば、… › アンインストール。ほかにも、見覚えのない最近の名前があれば書きとめます。
  2. 起動時に動くプログラム。同じアプリの中のスタートアップをクリックします。パソコンと一緒に起動するプログラムの一覧です。見覚えのないものを書きとめます。知らないプログラムのスイッチはオフにしてかまいません。削除されるわけではなく、自動で起動しなくなるだけです。
  3. 「遠隔操作」のプログラムは？ 技術者（Microsoft、銀行、プロバイダー）を名乗る人から電話があり、「画面を見るため」のプログラムを入れさせられた場合は、そのプログラムをアンインストールし、手順 4〜6 をよく読んでください。Microsoft も銀行も、そのような電話は決してしません。

3. ブラウザーを確認する

偽のソフトは、広告を出したり検索をのぞいたりするために、ブラウザー（Edge や Chrome）にも入りこむことがよくあります。

  1. 拡張機能（ブラウザーに追加される小さな部品）。Edge：右上の…メニュー › 拡張機能 › 拡張機能の管理。Chrome：⋮メニュー › 拡張機能 › 拡張機能を管理。自分で追加していないものは削除します。一覧が空なら、とてもよい状態です。
  2. 検索エンジン。Edge：…メニュー › 設定 › プライバシー、検索、サービス、いちばん下のアドレス バーと検索。Chrome：⋮メニュー › 設定 › 検索エンジン。よく知られた検索エンジン（Bing、Google、Qwant など）が表示されているはずです。偽のソフトがこの設定を自分のものに変えていることがあります。
  3. 最初に開くページ。ブラウザーを開いたときに知らないページが出る場合は、同じ設定の[スタート]、[ホーム]、および [新規] タブ（または「起動時」）で変えます。

4. 大切なパスワードを変える

なぜ？ 悪いプログラムの中には、キーボードで入力した内容を記録するものがあります。プログラムが入っていたあいだに、このパソコンで大切なサイトにログインした場合は、そのパスワードを変えたほうが安心です。
  1. このパソコンがきれいだと確かめられるまでは、できれば別の機器から（スマートフォンや別のパソコン）行います。
  2. この順番で：まずメール（ほかのすべてのアカウントを取り戻すのに使うため）、次に銀行、次にネットショッピングのサイト、最後にそのほか。
  3. サイトごとに別のパスワードを。全部を覚えずにすむコツは最初のガイド（手順 9）にあります。

5. メールを確認する

あなたのパスワードを手に入れた人が、パスワードを変えたあともメールを読み続けられるように、メールの中に「抜け道」を残していることがあります。正確な名前はメールのサービス（Gmail、Outlook、Orange、Yahoo など）によって違います。設定（歯車のマークが多いです）の中を探してください。

  1. 自動転送（「転送」「メールボックス」「アカウント」などの項目）：知らないアドレスへの転送がオンになっていないこと。
  2. フィルターやルール：自分で作っていないルールがないこと（たとえば、一部のメールを見えないうちに削除したり移動したりするルール）。
  3. 再設定用の情報（アカウントの「セキュリティ」）：電話番号と予備のアドレスが自分のものであること。
  4. 接続中の機器：多くのメールサービスで、機器や最近のログインの一覧が見られます。知らないものがあればすべての機器からログアウトを選び、自分の機器でログインし直します。
  5. まだの場合は、最初のガイドで説明している2段階認証をオンにします。

6. 銀行の情報を入力してしまった場合

あやしいサイトでカード番号を入力してしまった場合や、銀行のサイトを開いているあいだに偽の技術者に画面を見られた可能性がある場合は：

  • すぐに銀行に電話してください。カードや明細書に書いてある番号を使います（メッセージで届いた番号は使わないでください）。カードを止め、口座を見守ってもらえます。
  • 最近の明細を確認し、身に覚えのない取引があれば知らせます。
  • フランスでは、公式サイト cybermalveillance.gouv.fr（フランス語）で、状況に合わせた対処法や、必要な場合の被害届の出し方が説明されています。

7. もう起きないように

  • プログラムはMicrosoft Storeかメーカーの公式サイトからだけダウンロードし、広告からは決してダウンロードしない。
  • 変換・お掃除・高速化をうたう「無料」のプログラムには気をつける。Windows は PDF を（Edge で）開けますし、パソコンの手入れも自分でしてくれます。
  • 自分で何かをインストールしているわけではないのに「このアプリがデバイスに変更を加えることを許可しますか？」と聞かれたら、いいえを選ぶ。
  • きちんとした会社が、パソコンを「直す」ために電話してくることはありません。電話を切りましょう。
  • 「Windows パソコンを安全にする手順」を行う。きちんと設定したパソコンと最新のバックアップが、いちばんの守りです。
