どこから始める？

ご自分のこと、または身近な方のことで、気になっていることを選んでください。まずやるとよいことがすぐにわかり、必要ならもっと詳しい情報の場所もわかります。

だまされたかもしれません：やることを順番に

一人で抱えこまないでください。こうした詐欺はとても巧妙で、誰でもだまされます。早く動くほど、被害を小さくできます。
  1. すぐに銀行に電話してください。カードの裏や明細書に書いてある番号を使います（メッセージで届いた番号や、電話の相手が教えた番号は使わないでください）。カードを止めてもらい、身に覚えのない取引を知らせます。
  2. パソコンを誰かに「遠隔操作」された場合：電源を切り、アカウントにログインし直す前にガイド「ウイルスのあとに確認すること」を行ってください。
  3. パスワードや SMS のコードを教えてしまった場合：できれば別の機器から、まずメール、次に銀行のパスワードを変えます（やり方）。
  4. 助けを求める：フランスでは 17Cyber（17cyber.gouv.fr）と cybermalveillance.gouv.fr が、状況に合わせた対処法や被害届の出し方を案内しています（どちらもフランス語）。
  5. 身近な人に知らせる。一人で抱えこまないため、そしてその人が次に狙われないためです。

電話やメッセージがあやしいとき：覚えておきたい対応

  1. 電話を切る、または返事をしない。銀行、Microsoft、警察、税務署が、電話やメッセージでコードやパスワード、振り込みを求めることは決してありません。
  2. 自分からかけ直す。すでに知っている番号（カードの裏、電話帳）で、その機関や人に連絡します。「困っている孫」からなら、いつもの番号に直接かけましょう。
  3. 思いがけない SMS やメール（荷物、罰金、アカウントの停止）のリンクはクリックしない。サイトのアドレスは自分で入力します。
  4. 通報する：フランスでは、詐欺の SMS を 33700（無料）に転送し、あやしいサイトやメールは internet-signalement.gouv.fr（PHAROS）で通報できます。
  5. 迷惑電話を減らす：bloctel.gouv.fr（無料、フランスの番号）に番号を登録し、スマートフォンの着信フィルターをオンにします（iPhone は「不明な発信者を消音」、Android は「発信者番号とスパム」）。
冷蔵庫に貼っておきたい一言：「SMS で届いたコードは、誰にも教えない。」

パソコンにウイルスやあやしいプログラム

あわてなくて大丈夫です。よくあることで、直せます。Microsoft Defender が何か見つけた場合は、たいていもう隔離してくれています。

  1. Microsoft Defender のオフライン スキャンを行います（手順）。
  2. インストールされているプログラムとブラウザーを確認します。知らないものは削除しないでください。
  3. 大切なパスワードを、メールから順に変えます。

Windows パソコンを安全にする

ウイルス対策ソフトを買う必要はありません。Windows 11 は、きちんと設定すれば十分に守られています。特に役立つポイント：

  • ウイルス対策ソフトは1つだけ：最初から入っている Microsoft Defender。2つあるとじゃまし合います。
  • 自動の更新はオンのままに。
  • パソコンの起動時のコードと守られた Wi-Fi。
  • メールと銀行には2段階認証。
  • 書類と写真の自動バックアップ。

写真や書類をなくさないために

  1. かんたんな決まり：写真は2か所にあるようにします。スマートフォンやパソコンにしかないと、機器と一緒になくなることがあります。
  2. いちばん簡単なのは、インターネットへの自動バックアップです。iPhone なら iCloud 写真、Android なら Google フォト、Windows パソコンなら OneDrive か Google Drive。
  3. さらに、お好みで：月に一度つなぐ外付けハードディスク。
  4. ちゃんと動くか一度確かめる：別の機器から、バックアップした写真を開いてみます。

家族と連絡をとり続ける

  1. 家族がすでに使っているアプリを1つだけ選ぶ：多くは WhatsApp（メッセージ、写真、32人までのビデオ通話）、全員が iPhone か iPad なら FaceTime。
  2. 一緒にインストールし、家族の連絡先を写真つきで登録します。顔がわかる相手には電話をかけやすくなります。
  3. 孫が写真を送ってくれる家族のグループを作る。始めてみたくなるきっかけになることが多いです。
  4. 決まった時間（たとえば日曜日のビデオ通話）にすると、自然に習慣になります。
コツ：アプリのアイコンを最初の画面に大きく置き、その画面からほかのアイコンを外します。

初めての人の最初の機器

  • シニア向けスマートフォン（たとえば Doro のシリーズ、約150〜250 €）：大きなボタンとアイコン、大きな音、緊急ボタンつき。
  • または、ふつうのスマートフォンを「かんたんモード」で（入門用の Android で約150〜250 €）：あとで WhatsApp を使うなら便利です。
  • まずは1つだけ：電話をかける、出る。ほかはそのあとで。
買う前に：お店で試してみましょう。機能よりも、画面の見やすさとボタンの大きさが大切です。

とても高齢の人、体が弱い人の機器

わりと慣れている人の機器

毎日の健康

  • 病院の予約：フランスでは Doctolib。自分のアカウントに親を「家族」として追加すれば、離れていても予約を管理できます。
  • 薬：iPhone の「ヘルスケア」アプリや、MyTherapy などの無料アプリで知らせてもらえます。もっとかんたんにしたいなら、飲み忘れを家族に知らせるスマート薬ケースもあります。
  • オンライン診療：薬の継続や小さな不調に便利です。最初の予約の前に、ビデオ通話を一度試しておきましょう。
よい順番：まず道具を1つだけ2週間試し、必要ならもう1つ足します。

自宅で一人、安全に暮らす

  • ふつうの緊急通報サービス（téléassistance）：ボタンつきのペンダントや腕輪で、24時間対応のセンターにつながります。月に約20〜25 €。
  • 自動の転倒検知：本人がボタンを押せなくても知らせます。月に約25〜35 €。
  • 月額なし：SOS ボタンつきの電話や転倒検知つきの腕時計。家族に直接知らせます（センターにはつながりません）。
フランスの支援：緊急通報サービスの月額は50 % の税額控除の対象で（在宅サービスとして）、APA（高齢者自立手当）で一部がまかなえることもあります。県や共済保険（mutuelle）に独自の制度がある場合もあるので、市役所や地域の高齢者向け相談窓口で聞いてみましょう。
契約する前に：解約の条件（予告期間、最低契約期間）を読んでおきましょう。特に引っ越しや施設への入居のときに大切です。

苦手な人、使いたがらない人を手助けする

  1. 機器からではなく、その人が恋しく思っていることから始める：「スマートフォンを持ったほうがいいよ」より「孫の写真をもっと見たくない？」のほうが心が動きます。
  2. 1週間に1つだけ。1週目：電源を入れる・切る。2週目：電話をかける。3週目：写真を送る。
  3. 3-2-1 の方法：3回見せる、2回一緒にやる、1回一人でやってもらう。
  4. 機器はその人の手に持たせたままにし、手順を大きな字でカードに書いておきます。
  5. つまずいたら：休憩して、すでにできることを一度やり、別の日にまた続けます。
避けたい一言：「かんたんだよ！」。代わりに「わかるよ、最初は誰でも戸惑うよね」と言いましょう。

近くの無料の支援

  • デジタル相談員（conseillers numériques）と France Services の窓口：研修を受けた人が無料で、スマートフォンやパソコンの使い方、オンラインでの手続きを教えてくれます。場所の地図は societenumerique.gouv.fr にあります。市役所や図書館でも案内してもらえます。
  • Les Bons Clics（lesbonsclics.fr）：初心者向けの無料でかんたんな解説（フランス語）。
  • Emmaüs Connect（emmaus-connect.org）：サポートと、安い価格の整備済み機器。

親が一人ですべてを管理できなくなってきたら

フランスの法律には、軽いものからしっかり守るものまで、いくつかの制度があります。いつも、できるだけ制限の少ないものを選びます。

  • Mandat de protection future（将来保護委任）：本人が前もって、誰に世話を任せるかを自分で決めます。本人がまだ決められるうちに行う必要があります。
  • Habilitation familiale（家族による代理）：家族（子、配偶者、兄弟姉妹など）が、裁判官の許可を得て本人の代わりに手続きします。家族の仲がよい場合、いちばん簡単な方法であることが多いです。
  • Curatelle と tutelle（保佐・後見）：裁判官が決める、より広い支援です。
これは一般的な目安です。ご自分の状況については service-public.fr や公証人（notaire）に相談してください。高齢者への虐待は 3977 に電話してください。
