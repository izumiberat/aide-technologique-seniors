Sécuriser son ordinateur portable Windows, pas à pas

Pour Windows 11 · Mis à jour en novembre 2026

On me demande souvent : « Qu'est-ce que je dois faire pour que mon ordinateur soit protégé ? » Bonne nouvelle : Windows contient déjà presque tout ce qu'il faut. Il suffit de vérifier quelques réglages, une bonne fois pour toutes. Voici les étapes que je fais avec mes clients, expliquées simplement.

Prenez votre temps : vous pouvez faire une partie aujourd'hui et le reste un autre jour. Rien de ce qui est décrit ici ne risque d'abîmer votre ordinateur.

À avoir sous la main

  • Le mot de passe de votre ordinateur, si vous en avez un.
  • L'étiquette collée sous votre box internet (on y lit la clé du wifi).
  • Un papier et un crayon pour noter vos nouveaux codes.

1. Vérifier Sécurité Windows

Tapez « Sécurité Windows » dans la barre de recherche, en bas de l'écran, et ouvrez-la. C'est le tableau de bord de la protection de votre ordinateur.

  1. Les sites et programmes dangereux. Cliquez sur Contrôle des applications et du navigateur, puis sur le lien bleu Paramètres de protection fondée sur la réputation. Mettez tous les interrupteurs sur Activé (faites défiler la page jusqu'en bas). Windows vous préviendra avant d'ouvrir un site ou un programme connu pour être dangereux.
  2. Le pare-feu. Revenez à l'accueil avec la flèche ← en haut à gauche, puis cliquez sur Pare-feu et protection du réseau. Les trois réseaux doivent avoir une coche verte. Il n'y a rien à changer. Le pare-feu, c'est comme le gardien d'un immeuble : vous sortez librement, mais il ne laisse pas entrer les visiteurs que vous n'avez pas invités.
  3. Une protection en plus (facultatif). Dans Sécurité des appareils › Détails de l'isolation du noyau, activez Intégrité de la mémoire, puis redémarrez si Windows le demande. Si Windows refuse, c'est souvent à cause d'un vieil appareil (une imprimante, par exemple). Ce n'est pas grave : les autres protections suffisent.
  4. Les mises à jour. Fermez Sécurité Windows et ouvrez Paramètres (touche Windows + I). Allez dans Windows Update › Options avancées et activez « Recevoir les mises à jour pour d'autres produits Microsoft ». Les mises à jour bouchent les failles de sécurité dès qu'elles sont découvertes.
Vous avez encore Windows 10 ? Depuis octobre 2025, Microsoft ne publie plus de mises à jour de sécurité gratuites pour Windows 10. Selon l'âge de votre ordinateur, il est possible de passer à Windows 11. On peut regarder ensemble ce qui est le plus simple pour vous.

2. Garder un seul antivirus

Pourquoi ? Windows contient déjà un antivirus gratuit et efficace : Microsoft Defender. Beaucoup d'ordinateurs ont en plus un antivirus « gratuit », installé à l'achat ou en même temps qu'un autre programme. Deux antivirus en même temps ralentissent l'ordinateur et affichent beaucoup de messages, souvent pour vous vendre une version payante. Un seul suffit.
  1. Ouvrez Paramètres, puis Applications › Applications installées.
  2. Dans la case de recherche, tapez le nom de l'autre antivirus.
  3. Sur chaque ligne qui porte son nom : cliquez sur les trois points … › Désinstaller. Certains antivirus installent plusieurs morceaux (VPN, gestionnaire de mots de passe…) : retirez-les tous.
  4. Dans votre navigateur (Edge ou Chrome), ouvrez le menu › Extensions et retirez l'extension de cet antivirus, s'il y en a une.
  5. Redémarrez l'ordinateur. Microsoft Defender reprend la main tout seul.

Si vous avez payé un antivirus et qu'il est à jour, vous pouvez bien sûr le garder. L'important est de ne pas en avoir deux.

3. Vérifier que Microsoft Defender est en marche

  1. Rouvrez Sécurité Windows › Protection contre les virus et menaces. Il doit être écrit « Antivirus Microsoft Defender ».
  2. Cliquez sur Gérer les paramètres et vérifiez que ces quatre interrupteurs sont sur Activé :
    • Protection en temps réel : Defender surveille en permanence ce que vous ouvrez et téléchargez.
    • Protection dans le cloud : il consulte la liste des menaces les plus récentes, mise à jour en continu.
    • Envoi automatique d'échantillons : un fichier suspect est envoyé à Microsoft pour analyse. Windows vous demande toujours avant d'envoyer un fichier qui pourrait être personnel.
    • Protection contre les falsifications : empêche un programme malveillant d'éteindre Defender en cachette.
  3. Lancez une Analyse rapide (quelques minutes).

Vous verrez peut-être un message jaune sur la « Protection contre les ransomware » qui propose de configurer OneDrive. Vous pouvez cliquer sur Ignorer pour l'instant : c'est une question de sauvegarde de vos fichiers, un vrai sujet, qui mérite qu'on le regarde tranquillement à part.

4. En cas de doute : l'analyse « hors ligne »

Pourquoi ? Si vous avez installé un programme douteux (un « convertisseur PDF gratuit », un faux nettoyeur…), ou si l'ordinateur se comporte bizarrement, cette analyse redémarre l'ordinateur et le vérifie avant que Windows ne se lance. Un programme malveillant ne peut donc pas se cacher pendant qu'on le cherche.
  1. Enregistrez votre travail et fermez vos documents : l'ordinateur va redémarrer.
  2. Ouvrez Sécurité Windows › Protection contre les virus et menaces › Options d'analyse.
  3. Choisissez Analyse Microsoft Defender hors ligne, puis Analyser maintenant.
  4. L'analyse dure une quinzaine de minutes, puis Windows redémarre normalement.

Si Defender a trouvé quelque chose, il le met en quarantaine. Par précaution, changez ensuite les mots de passe des sites importants (banque, boîte mail, achats en ligne), de préférence depuis un autre appareil.

5. Un code au démarrage de l'ordinateur

Pourquoi ? Beaucoup d'ordinateurs s'ouvrent directement, sans rien demander. Toute personne qui l'allume (ou qui le volerait) arrive alors sur vos e-mails, vos documents et les mots de passe enregistrés dans le navigateur. Un code au démarrage ferme cette porte.

Le plus simple est un code PIN de 4 à 6 chiffres (Windows l'appelle « code confidentiel »). Il est plus rapide à taper qu'un mot de passe et ne fonctionne que sur cet ordinateur.

  1. Ouvrez Paramètres › Comptes › Options de connexion.
  2. Cliquez sur Code confidentiel (Windows Hello), puis Configurer.
  3. Windows demande d'abord le mot de passe actuel du compte. S'il n'en demande aucun, c'est que le compte n'en a pas : cliquez d'abord sur Mot de passe › Ajouter, puis revenez ici.
  4. Choisissez un code. Évitez 1234, 0000 et les dates de naissance de la famille.
  5. Notez-le sur un papier rangé à la maison, mais pas collé sur l'ordinateur.

Toujours dans Options de connexion, à la question « Si vous vous êtes absenté, quand Windows doit-il vous demander de vous reconnecter ? », choisissez Lorsque le PC sort de la veille.

Pour tester : appuyez sur touche Windows + L. L'écran se verrouille, et votre code le rouvre. C'est aussi le bon réflexe quand vous vous éloignez de l'ordinateur.

6. Un wifi bien protégé à la maison

Pourquoi ? Le wifi passe dans l'air. La box le « chiffre », c'est-à-dire qu'elle le brouille pour que seuls vos appareils puissent le lire. Certaines box acceptent encore une ancienne façon de brouiller (appelée TKIP), que des personnes malintentionnées savent contourner. Si votre iPhone affiche « Sécurité faible » sous le nom de votre wifi, c'est souvent ça : c'est un réglage de la box à changer, pas le téléphone.
  1. Sur un ordinateur connecté à votre wifi, ouvrez le navigateur et tapez dans la barre d'adresse, tout en haut, l'adresse de votre box. Elle figure dans le livret de votre fournisseur. Chez Orange (Livebox), c'est 192.168.1.1.
  2. Connectez-vous. Le mot de passe est indiqué dans le livret ou sur l'étiquette de la box (sur une Livebox, ce sont en général les 8 premiers caractères de la clé de sécurité).
  3. Cherchez la page Wifi (parfois « Wifi avancé »), puis le réglage Mode de sécurité ou Chiffrement.
  4. Choisissez WPA2 avec AES (ou WPA3 si votre box le propose et que tous vos appareils sont récents). Évitez tout ce qui contient « TKIP », « mixte », « WEP » ou « aucune ».
  5. Ne changez ni le nom du wifi ni la clé : vos appareils se reconnecteront tout seuls.
  6. Enregistrez. Le wifi se coupe environ une minute, puis revient : c'est normal.
Attention : sur la page de la box, ne cliquez jamais sur « mot de passe oublié ». La box propose alors de revenir à ses réglages d'usine, ce qui oblige à tout reconnecter. Si le mot de passe ne marche pas, arrêtez-vous là : votre wifi continue de fonctionner comme avant.

Si un appareil très ancien ne se reconnecte plus, on peut remettre l'ancien réglage le temps de trouver une solution pour lui.

7. Le téléphone et WhatsApp

Le téléphone contient autant de choses importantes que l'ordinateur : vos messages, vos photos, votre boîte mail, et c'est souvent lui qui reçoit les codes de la banque. Quelques réglages suffisent.

Sur un iPhone (application Réglages)

  • Mises à jour : Général › Mise à jour logicielle › Mises à jour automatiques : activez tout.
  • Code de déverrouillage : Face ID et code (ou Touch ID et code). Un code à 6 chiffres, pas 123456 ni une date de naissance.
  • Verrouillage automatique : Luminosité et affichage › Verrouillage automatique : 1 ou 2 minutes.
  • Protection en cas de vol : Face ID et code › Protection en cas de vol de l'appareil. Même si un voleur connaît votre code, il ne pourra pas changer vos mots de passe hors de chez vous. Elle nécessite que « Localiser » soit activé : cette fonction ne partage votre position avec personne, elle sert seulement à vous permettre de retrouver ou d'effacer votre téléphone. C'est vous qui choisissez.
  • Qui voit quoi : Confidentialité et sécurité › Contrôle de sécurité. L'iPhone vous montre qui voit votre position ou vos photos, et vous pouvez tout arrêter d'un geste.
  • Sites frauduleux : Apps › Safari › Avertissement de site frauduleux : activé.

Sur un téléphone Android, les mêmes réglages existent avec des noms un peu différents selon la marque.

Dans WhatsApp (Vous ou Réglages, en bas à droite)

  • Validation en deux étapes : Compte › Validation en deux étapes › Activer. Choisissez un code à 6 chiffres (différent de celui du téléphone) et notez-le. Sans ce code, personne ne peut installer votre WhatsApp sur un autre téléphone, même avec votre numéro.
  • Appareils connectés : vérifiez qu'il n'y a que vos ordinateurs ou tablettes. Si vous en voyez un inconnu, touchez-le puis Déconnexion.
  • Groupes : Confidentialité › Groupes › Mes contacts. Cela évite d'être ajouté dans des groupes d'inconnus, souvent des arnaques.
  • Appels d'inconnus : Confidentialité › Appels › Mettre en silence les appels inconnus.
La règle d'or : ne donnez jamais à personne un code reçu par SMS, même à un « ami » qui écrit sur WhatsApp qu'il vous l'a envoyé par erreur. C'est l'arnaque la plus courante pour voler un compte. Dans le doute, appelez la personne.

8. Les bons réflexes à retenir

  • Le petit bouclier en bas à droite de l'écran : vert, tout va bien. Jaune ou rouge, cliquez dessus et Windows vous dit quoi faire.
  • Un message qui vous demande de payer pour « nettoyer » ou « débloquer » votre ordinateur est une arnaque : fermez-le, n'appelez aucun numéro affiché.
  • Un mail ou un SMS qui réclame votre mot de passe ou vous presse de cliquer : ne cliquez pas, et demandez à un proche.
  • Touche Windows + L quand vous vous éloignez de l'ordinateur.
  • Un mot de passe différent pour chaque site important, et la validation en deux étapes sur votre boîte mail.
  • Vos photos et papiers importants méritent une sauvegarde (OneDrive ou disque externe), pour ne rien perdre en cas de panne.

Petit lexique

Antivirus
Programme qui repère et bloque les logiciels malveillants. Un seul suffit.
Pare-feu
Filtre qui empêche les connexions non autorisées vers votre ordinateur.
Mise à jour
Correction envoyée par Microsoft ou Apple, souvent pour boucher une faille de sécurité.
Chiffrement
Brouillage des informations pour que seuls ceux qui ont la clé puissent les lire.
WPA2 / AES
La protection actuelle du wifi. TKIP est une ancienne protection, déconseillée.
Code PIN (Windows Hello)
Code qui ouvre votre session, valable uniquement sur cet ordinateur.
Validation en deux étapes
Connexion qui demande le mot de passe plus un code reçu sur le téléphone.
Analyse hors ligne
Vérification de l'ordinateur faite avant que Windows ne démarre.
