Sécuriser son ordinateur portable Windows, pas à pas

Pour Windows 11 · Mis à jour le 19 novembre 2026

On me demande souvent : « Qu'est-ce que je dois faire pour que mon ordinateur soit protégé ? » Bonne nouvelle : Windows contient déjà presque tout ce qu'il faut. Il suffit de vérifier quelques réglages, une bonne fois pour toutes. Voici les étapes que je fais avec mes clients, expliquées simplement.

Prenez votre temps : vous pouvez faire une partie aujourd'hui et le reste un autre jour. Rien de ce qui est décrit ici ne risque d'abîmer votre ordinateur.

Par où commencer ? Les étapes 1 à 3 sont les plus importantes (environ 30 minutes en tout), avec la sauvegarde (étape 8) si vous ne l'avez pas encore. Les autres peuvent attendre. Si une étape vous paraît compliquée, passez à la suivante : vous y reviendrez plus tard, ou on la fera ensemble.

À avoir sous la main

  • Le mot de passe de votre ordinateur, si vous en avez un.
  • L'étiquette collée sous votre box internet (on y lit la clé du wifi).
  • Un papier et un crayon pour noter vos nouveaux codes.

Deux repères utiles : la barre de recherche est la case « Rechercher » en bas de l'écran, à côté du logo Windows (si vous ne la voyez pas, cliquez sur le logo Windows, puis tapez directement). La touche Windows est la touche du clavier qui porte ce même logo, en bas à gauche, entre Ctrl et Alt.

1. Vérifier Sécurité Windows

Tapez « Sécurité Windows » dans la barre de recherche, en bas de l'écran, et ouvrez-la. C'est le tableau de bord de la protection de votre ordinateur.

Si certains réglages sont grisés (on ne peut pas cliquer dessus), c'est souvent qu'un autre antivirus est installé : faites d'abord l'étape 2, puis revenez ici.

  1. Les sites et programmes dangereux. Cliquez sur Contrôle des applications et du navigateur, puis sur le lien bleu Paramètres de protection fondée sur la réputation. Mettez tous les interrupteurs sur Activé (faites défiler la page jusqu'en bas). Windows vous préviendra avant d'ouvrir un site ou un programme connu pour être dangereux.
  2. Le pare-feu. Revenez à l'accueil avec la flèche ← en haut à gauche, puis cliquez sur Pare-feu et protection du réseau. Les trois réseaux doivent avoir une coche verte. Il n'y a rien à changer. Le pare-feu, c'est comme le gardien d'un immeuble : vous sortez librement, mais il ne laisse pas entrer les visiteurs que vous n'avez pas invités.
  3. Une protection en plus (facultatif, vous pouvez sauter ce point). Revenez à l'accueil, puis allez dans Sécurité des appareils › Détails de l'isolation du noyau, activez Intégrité de la mémoire, puis redémarrez si Windows le demande. Si Windows refuse, c'est souvent à cause d'un vieil appareil (une imprimante, par exemple). Ce n'est pas grave : les autres protections suffisent.
  4. Les mises à jour. Fermez Sécurité Windows et ouvrez Paramètres (touche Windows + I). Allez dans Windows Update › Options avancées et activez « Recevoir les mises à jour pour d'autres produits Microsoft ». Les mises à jour bouchent les failles de sécurité dès qu'elles sont découvertes.
Vous avez encore Windows 10 ? Depuis octobre 2025, Microsoft ne publie plus de mises à jour de sécurité gratuites pour Windows 10. Selon l'âge de votre ordinateur, il est possible de passer à Windows 11. On peut regarder ensemble ce qui est le plus simple pour vous.

2. Garder un seul antivirus

Pourquoi ? Windows contient déjà un antivirus gratuit et efficace : Microsoft Defender. Beaucoup d'ordinateurs ont en plus un antivirus « gratuit », installé à l'achat ou avec un autre programme téléchargé. Deux antivirus en même temps ralentissent l'ordinateur et affichent beaucoup de messages, souvent pour vous vendre une version payante. Un seul suffit.
  1. Ouvrez Paramètres, puis Applications › Applications installées.
  2. Dans la case de recherche, tapez le nom de l'autre antivirus. Vous ne le connaissez pas ? Dans Sécurité Windows › Protection contre les virus et menaces, Windows affiche le nom de l'antivirus qui est actif. Vous pouvez aussi taper simplement « antivirus » ou « security » et regarder ce qui apparaît.
  3. Sur chaque ligne qui porte son nom : cliquez sur les trois points … › Désinstaller. Suivez les écrans de désinstallation jusqu'au bout : ils essaient souvent de vous faire changer d'avis, répondez que vous voulez bien désinstaller. Certains antivirus installent plusieurs morceaux qui portent le même nom de marque : retirez-les tous.
  4. Dans votre navigateur (Edge ou Chrome), ouvrez le menu (les trois points en haut à droite) › Extensions. Les extensions sont de petits modules ajoutés au navigateur. Si l'une porte le nom de cet antivirus, cliquez sur Supprimer.
  5. Redémarrez l'ordinateur. Microsoft Defender reprend la main tout seul.

Si vous avez payé un antivirus et qu'il est à jour, vous pouvez bien sûr le garder. L'important est de ne pas en avoir deux.

3. Vérifier que Microsoft Defender est en marche

  1. Rouvrez Sécurité Windows › Protection contre les virus et menaces. Il doit être écrit « Antivirus Microsoft Defender ».
  2. Cliquez sur Gérer les paramètres et vérifiez que ces quatre interrupteurs sont sur Activé :
    • Protection en temps réel : Defender surveille en permanence ce que vous ouvrez et téléchargez.
    • Protection dans le cloud : il consulte sur internet la liste des menaces les plus récentes, mise à jour en continu.
    • Envoi automatique d'échantillons : un fichier suspect est envoyé à Microsoft pour analyse. Windows vous demande toujours avant d'envoyer un fichier qui pourrait être personnel.
    • Protection contre les falsifications : empêche un programme malveillant d'éteindre Defender en cachette.
  3. Lancez une Analyse rapide (quelques minutes).

Vous verrez peut-être un message jaune sur la « Protection contre les ransomware » (des logiciels qui prennent vos fichiers en otage) qui propose de configurer OneDrive. Vous pouvez cliquer sur Ignorer pour l'instant : c'est une question de sauvegarde de vos fichiers, expliquée tranquillement à l'étape 8.

4. En cas de doute : l'analyse « hors ligne »

Pourquoi ? Si vous avez installé un programme douteux (un « convertisseur PDF gratuit », un faux nettoyeur…), ou si l'ordinateur se comporte bizarrement, cette analyse redémarre l'ordinateur et le vérifie avant que Windows ne se lance. Un programme malveillant ne peut donc pas se cacher pendant qu'on le cherche.
  1. Enregistrez votre travail et fermez vos documents : l'ordinateur va redémarrer.
  2. Ouvrez Sécurité Windows › Protection contre les virus et menaces › Options d'analyse.
  3. Choisissez Analyse Microsoft Defender hors ligne, puis Analyser maintenant.
  4. L'analyse dure une quinzaine de minutes, puis Windows redémarre normalement.

Si Defender a trouvé quelque chose, il le met en quarantaine. Pour la suite (programmes à vérifier, mots de passe à changer, boîte mail), suivez mon guide Après un virus : les vérifications à faire.

5. Un code au démarrage de l'ordinateur

Pourquoi ? Beaucoup d'ordinateurs s'ouvrent directement, sans rien demander. Toute personne qui l'allume (ou qui le volerait) arrive alors sur vos e-mails, vos documents et les mots de passe enregistrés dans le navigateur. Un code au démarrage ferme cette porte.

Le plus simple est un code PIN de 4 à 6 chiffres (Windows l'appelle « code confidentiel »). Il est plus rapide à taper qu'un mot de passe et ne fonctionne que sur cet ordinateur.

  1. Ouvrez Paramètres › Comptes › Options de connexion.
  2. Cliquez sur Code confidentiel (Windows Hello), puis Configurer.
  3. Windows demande d'abord le mot de passe actuel du compte. S'il n'en demande aucun, c'est que le compte n'en a pas : cliquez d'abord sur Mot de passe › Ajouter, puis revenez ici.
  4. Choisissez un code. Évitez 1234, 0000 et les dates de naissance de la famille.
  5. Notez-le sur un papier rangé à la maison, mais pas collé sur l'ordinateur.

Toujours dans Options de connexion, à la question « Si vous vous êtes absenté, quand Windows doit-il vous demander de vous reconnecter ? », choisissez Lorsque le PC sort de la veille.

Pour tester : appuyez sur touche Windows + L. L'écran se verrouille, et votre code le rouvre. C'est aussi le bon réflexe quand vous vous éloignez de l'ordinateur.

6. Un wifi et une box bien protégés

C'est l'étape la plus technique de ce guide. Si vous hésitez, gardez-la pour une visite : votre wifi continue de marcher en attendant.

Pourquoi ? Le wifi passe dans l'air. La box le « chiffre », c'est-à-dire qu'elle le brouille pour que seuls vos appareils puissent le lire. Certaines box acceptent encore une ancienne façon de brouiller (appelée TKIP), que des personnes malintentionnées savent contourner. Si votre iPhone affiche « Sécurité faible » sous le nom de votre wifi, c'est souvent ça : c'est un réglage de la box à changer, pas le téléphone.
  1. Sur un ordinateur connecté à votre wifi, ouvrez le navigateur et tapez l'adresse de votre box dans la barre d'adresse, tout en haut de la fenêtre (là où s'affiche l'adresse des sites, pas dans la case de recherche de Google), puis appuyez sur Entrée. Elle figure dans le livret de votre fournisseur. Chez Orange (Livebox), c'est 192.168.1.1.
  2. Connectez-vous. Le mot de passe est indiqué dans le livret ou sur l'étiquette de la box (sur une Livebox, ce sont en général les 8 premiers caractères de la clé de sécurité).
  3. Cherchez la page Wifi (parfois « Wifi avancé »), puis le réglage Mode de sécurité ou Chiffrement.
  4. Choisissez WPA2 avec AES (ou WPA3 si votre box le propose et que tous vos appareils sont récents). Évitez tout ce qui contient « TKIP », « mixte », « WEP » ou « aucune ».
  5. Ne changez ni le nom du wifi ni la clé : vos appareils se reconnecteront tout seuls.
  6. Enregistrez. Le wifi se coupe environ une minute, puis revient : c'est normal.
Attention : sur la page de la box, ne cliquez jamais sur « mot de passe oublié ». La box propose alors de revenir à ses réglages d'usine, ce qui oblige à tout reconnecter. Si le mot de passe ne marche pas, arrêtez-vous là : votre wifi continue de fonctionner comme avant.

Si un appareil très ancien ne se reconnecte plus, on peut remettre l'ancien réglage le temps de trouver une solution pour lui.

Pendant que vous êtes sur la page de la box

  • Qui est connecté chez vous ? Cherchez la page qui liste les appareils connectés (souvent « Mon réseau » ou « Équipements »). Vous devez reconnaître chaque appareil : ordinateur, téléphones, télévision, imprimante… Si un appareil inconnu apparaît, le plus simple est de changer la clé du wifi : seuls ceux qui la connaissent pourront se reconnecter (il faudra la retaper sur chacun de vos appareils).
  • Le wifi invités. Beaucoup de box proposent un wifi « invités ». Activez-le pour les visiteurs : ils ont internet, mais n'ont pas accès à vos appareils, et vous n'avez pas à donner votre clé principale.
  • Le bouton WPS. Il permet de connecter un appareil sans taper la clé. Si vous ne vous en servez jamais, vous pouvez le désactiver dans les réglages wifi : c'est une porte d'entrée de moins.
  • Les mises à jour de la box se font en général toutes seules, la nuit, par votre fournisseur. Laissez simplement la box allumée.
  • Terminez en cliquant sur Se déconnecter en haut de la page de la box.

7. Le téléphone et WhatsApp

Le téléphone contient autant de choses importantes que l'ordinateur : vos messages, vos photos, votre boîte mail, et c'est souvent lui qui reçoit les codes de la banque. Quelques réglages suffisent.

Sur un iPhone (application Réglages)

  • Mises à jour : Général › Mise à jour logicielle › Mises à jour automatiques : activez tout.
  • Code de déverrouillage : Face ID et code (ou Touch ID et code). Un code à 6 chiffres, pas 123456 ni une date de naissance.
  • Verrouillage automatique : Luminosité et affichage › Verrouillage automatique : 1 ou 2 minutes.
  • Protection en cas de vol : Face ID et code › Protection en cas de vol de l'appareil. Même si un voleur connaît votre code, il ne pourra pas changer vos mots de passe hors de chez vous. Elle nécessite que « Localiser » soit activé : cette fonction ne partage votre position avec personne, elle sert seulement à vous permettre de retrouver ou d'effacer votre téléphone. C'est vous qui choisissez.
  • Qui voit quoi : Confidentialité et sécurité › Contrôle de sécurité. L'iPhone vous montre qui voit votre position ou vos photos, et vous pouvez tout arrêter d'un geste.
  • Sites frauduleux : Apps › Safari › Avertissement de site frauduleux : activé.

Sur un téléphone Android, les mêmes réglages existent avec des noms un peu différents selon la marque.

Dans WhatsApp (Vous ou Réglages, en bas à droite)

  • Validation en deux étapes : Compte › Validation en deux étapes › Activer. Choisissez un code à 6 chiffres (différent de celui du téléphone) et notez-le. Sans ce code, personne ne peut installer votre WhatsApp sur un autre téléphone, même avec votre numéro.
  • Appareils connectés : vérifiez qu'il n'y a que vos ordinateurs ou tablettes. Si vous en voyez un inconnu, touchez-le puis Déconnexion.
  • Groupes : Confidentialité › Groupes › Mes contacts. Cela évite d'être ajouté dans des groupes d'inconnus, souvent des arnaques.
  • Appels d'inconnus : Confidentialité › Appels › Mettre en silence les appels inconnus.
La règle d'or : ne donnez jamais à personne un code reçu par SMS, même à un « ami » qui écrit sur WhatsApp qu'il vous l'a envoyé par erreur. C'est l'arnaque la plus courante pour voler un compte. Dans le doute, appelez la personne.

8. Sauvegarder vos fichiers automatiquement

Pourquoi ? Un ordinateur peut tomber en panne, être volé, ou être bloqué par un virus. Vos photos et vos papiers, eux, ne se remplacent pas. Une sauvegarde automatique en fait une copie régulière, sans que vous ayez à y penser.

La solution intégrée à Windows : l'Historique des fichiers

Windows sait copier tout seul vos dossiers (Documents, Images, Bureau, Musique, Vidéos) sur un disque externe ou un boîtier de sauvegarde, toutes les heures, en gardant les anciennes versions de vos fichiers.

  1. Branchez votre disque externe ou vérifiez que votre boîtier de sauvegarde est allumé.
  2. Dans la barre de recherche, tapez « Historique des fichiers » et ouvrez-le (il s'ouvre dans le Panneau de configuration).
  3. Si votre disque apparaît, cliquez sur Activer. S'il n'apparaît pas, cliquez sur Sélectionner un lecteur à gauche et choisissez-le. Pour un boîtier relié à la box plutôt qu'à l'ordinateur, cliquez sur Ajouter un emplacement réseau.
  4. Dans Paramètres avancés, vous pouvez garder « Toutes les heures » et « Pour toujours » (ou « Jusqu'à ce que de l'espace soit nécessaire »).
  5. Laissez la première sauvegarde se terminer : elle peut prendre un moment. Les suivantes sont rapides.

Pour vérifier que ça marche, faites un essai une fois : dans le même écran, cliquez sur Restaurer des fichiers personnels et retrouvez une photo. Une sauvegarde qu'on n'a jamais essayée est une sauvegarde dont on n'est pas sûr.

Vous avez un boîtier « RAID » ?

Un boîtier RAID contient deux disques qui gardent la même copie. Si l'un tombe en panne, l'autre prend le relais : c'est une bonne protection contre la panne d'un disque. Mais ce n'est pas une sauvegarde complète : si un fichier est effacé par erreur ou abîmé par un virus, il l'est sur les deux disques à la fois. Et en cas de vol ou d'incendie, ordinateur et boîtier disparaissent ensemble. D'où les deux conseils suivants.

Deux précautions qui font toute la différence

  • Gardez des anciennes versions. L'Historique des fichiers le fait déjà. Si votre boîtier est relié à la box, regardez aussi dans ses réglages s'il propose des « instantanés » ou un « historique des versions », et activez-les. Ainsi, même si un virus abîme vos fichiers, vous pouvez revenir à la version de la veille.
  • Une copie ailleurs qu'à la maison. Pour vos fichiers les plus précieux (photos de famille, papiers importants), gardez une deuxième copie hors de chez vous : en ligne, avec OneDrive ou Google Drive (voir plus bas), ou sur un petit disque que vous mettez à jour une fois par mois et que vous rangez chez un proche.

Si votre disque de sauvegarde se branche sur l'ordinateur par un câble, ne le laissez pas branché en permanence : branchez-le une fois par semaine, le temps que la sauvegarde se fasse. Un disque débranché est à l'abri d'un virus.

Sauvegarder en ligne : OneDrive ou Google Drive

C'est la façon la plus simple d'avoir une copie hors de la maison : vos dossiers sont copiés sur internet, automatiquement, dès que l'ordinateur est connecté. Choisissez l'un ou l'autre, pas les deux sur les mêmes dossiers.

Avec OneDrive (déjà installé sur Windows 11, il faut un compte Microsoft) :

  1. En bas à droite de l'écran, près de l'heure, cliquez sur le petit nuage (s'il n'apparaît pas, cliquez d'abord sur la petite flèche ^). Si on vous le demande, connectez-vous avec votre compte Microsoft.
  2. Cliquez sur la roue dentée en haut à droite, puis Paramètres.
  3. Dans Synchroniser et sauvegarder, cliquez sur Gérer la sauvegarde.
  4. Choisissez les dossiers à protéger (Bureau, Documents, Images), puis Démarrer la sauvegarde.

Vos fichiers restent au même endroit sur l'ordinateur, mais ils sont maintenant aussi dans OneDrive. Une petite coche verte ou un nuage à côté de chaque fichier indique qu'il est bien copié.

Avec Google Drive (il faut un compte Google, par exemple une adresse Gmail) :

  1. Sur le site de Google, cherchez « Google Drive pour ordinateur », téléchargez-le depuis la page officielle de Google, puis installez-le.
  2. Connectez-vous avec votre compte Google.
  3. Cliquez sur l'icône Google Drive près de l'heure, puis sur la roue dentée › Préférences.
  4. Dans Mon ordinateur, cliquez sur Ajouter un dossier, choisissez par exemple Documents, puis Synchroniser avec Google Drive et OK. Faites de même pour vos autres dossiers importants.

Bon à savoir pour les deux :

  • La place gratuite est limitée : 5 Go chez Microsoft, 15 Go chez Google (partagés avec vos mails). C'est assez pour des papiers, souvent trop peu pour des années de photos. Au-delà, il faut un abonnement payant : comparez avant de choisir, et commencez par vos fichiers les plus précieux.
  • Ce qui est effacé sur l'ordinateur l'est aussi en ligne, mais reste récupérable pendant environ 30 jours dans la corbeille du site OneDrive ou Google Drive.
  • La sécurité de cette copie dépend de votre compte : protégez-le avec un bon mot de passe et la validation en deux étapes (voir l'étape 9).

9. Votre boîte mail et vos mots de passe

Pourquoi ? Votre boîte mail est la clé de tous vos autres comptes : c'est là qu'arrivent les liens « mot de passe oublié ». Quelqu'un qui entre dans votre boîte mail peut ensuite entrer presque partout. C'est donc elle qu'on protège en premier.
  1. Activez la validation en deux étapes sur votre boîte mail. En plus du mot de passe, il faudra un code reçu sur votre téléphone, mais seulement quand vous vous connectez depuis un nouvel appareil. Cherchez ce réglage dans les paramètres de votre compte, rubrique « Sécurité » (Gmail, Outlook, Orange, Yahoo… le proposent tous). Faites de même pour votre compte Microsoft ou Google si vous sauvegardez en ligne.
  2. Vérifiez vos moyens de récupération : dans la même rubrique, le numéro de téléphone et l'adresse de secours doivent être les vôtres et à jour.
  3. Un mot de passe différent pour chaque site important (mail, banque, achats en ligne). Si un site se fait voler ses mots de passe, les autres restent à l'abri.
  4. Pour ne pas avoir à tout retenir, laissez votre navigateur (Edge ou Chrome) proposer et enregistrer des mots de passe solides pour vous : il les remplit tout seul. C'est sûr à condition que l'ordinateur soit protégé par un code au démarrage (étape 5). Gardez sur papier, à la maison, le mot de passe de votre boîte mail.

10. Les bons réflexes à retenir

  • Le petit bouclier en bas à droite de l'écran : vert, tout va bien. Jaune ou rouge, cliquez dessus et Windows vous dit quoi faire.
  • Un message qui vous demande de payer pour « nettoyer » ou « débloquer » votre ordinateur est une arnaque : fermez-le, n'appelez aucun numéro affiché.
  • Un mail ou un SMS qui réclame votre mot de passe ou vous presse de cliquer : ne cliquez pas, et demandez à un proche.
  • Touche Windows + L quand vous vous éloignez de l'ordinateur.
  • Un mot de passe différent pour chaque site important, et la validation en deux étapes sur votre boîte mail.
  • Une sauvegarde automatique, des anciennes versions, et une copie de vos fichiers précieux hors de la maison.

Petit lexique

Antivirus
Programme qui repère et bloque les logiciels malveillants. Un seul suffit.
Pare-feu
Filtre qui empêche les connexions non autorisées vers votre ordinateur.
Mise à jour
Correction envoyée par Microsoft ou Apple, souvent pour boucher une faille de sécurité.
Chiffrement
Brouillage des informations pour que seuls ceux qui ont la clé puissent les lire.
WPA2 / AES
La protection actuelle du wifi. TKIP est une ancienne protection, déconseillée.
Code PIN (Windows Hello)
Code qui ouvre votre session, valable uniquement sur cet ordinateur.
Validation en deux étapes
Connexion qui demande le mot de passe plus un code reçu sur le téléphone.
Analyse hors ligne
Vérification de l'ordinateur faite avant que Windows ne démarre.
